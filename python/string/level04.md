String Level 4 — Pattern Roadmap
#	Pattern	What you need to learn
1	Sliding Window	left, right, expand/shrink window
2	HashMap + Sliding Window	Frequency dictionary + window
3	Two Pointers	left, right, move pointers based on condition
4	Stack	Push/pop, matching, adjacent removal
5	Palindrome Logic	Two pointers, expand around center
6	Substring Problems	Finding/optimizing substrings using the above patterns
